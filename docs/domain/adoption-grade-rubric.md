# 도입 등급 5축 루브릭 (v1.0)

설계서 §1.4·§D.3 기준. 5축 점수의 가중합으로 `adoption_grade`를 산출한다.

## 5축 정의 (각 0~5점)
| 축 | 정의 | 5점 예시 | 0점 예시 |
|---|------|--------|---------|
| **data** (데이터 적합성) | 한국 보험사가 이 자료에 필요한 데이터를 보유할 가능성 | 표준 경험사망률·생명표 활용 | 미국 의료기록 등 한국 미보유 데이터 의존 |
| **regulation** (규제 정합성) | K-ICS·IFRS17 등 현행 규제와의 충돌 가능성 | 현행 규제 보완·지원 방향 | 명백한 규제 충돌 |
| **product** (상품 적용성) | 한국 시장의 주력 상품 라인에 적용 가능한 정도 | 보장성·연금 핵심 가정에 직접 반영 | 한국 미판매 상품 한정 |
| **difficulty** (도입 난이도, 반전: 낮을수록 5점) | 시스템·프로세스 변경 부담 | 가정·파라미터 교체만으로 가능 | 시스템 전면 개편 필요 |
| **effect** (기대 효과) | 도입 시 손익·리스크·자본에 미치는 영향 크기 | 자본요구액 5% 이상 변동 가능 | 학술적 흥미 수준 |

## 초기 가중치 (v1.0 — 분기 회고로 조정)
```
data:       0.30
regulation: 0.25
product:    0.20
difficulty: 0.15
effect:     0.10
```
가중합 = Σ(축점수 × 가중치). 0~5 범위.

## 가중합 → adoption_grade 매핑 (v1.0)
| 가중합 | grade |
|------|------|
| ≥ 3.8 | `immediate` (즉시활용) |
| 3.0 ~ 3.79 | `pilot` (파일럿) |
| 2.0 ~ 2.99 | `internal_research` (내부연구) |
| < 2.0 | `monitoring` (모니터링) |

## 분기 회고 양식
1. 직전 3개월 published 자료의 5축 점수 분포 (산점도·히스토그램)
2. 회원·관리자 피드백 중 등급 이의 비율
3. 깊이 단계 분포 (어떤 트랙·region이 `interpreted`까지 도달)
4. 자동 수집 캐치율 (소스별 발행 vs `aik_discovery_runs`)
5. 권장 가중치 조정안 (±0.05 단위) + 영향 시뮬레이션
6. 결정 사항 → 본 문서 v버전 ↑ + `aik_audit_log`에 기록
